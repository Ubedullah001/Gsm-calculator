
# Textile GSM Calculator

A web application developed using Python and Streamlit
for calculating the GSM of textile fabrics.

## Features

- Calculate fabric GSM.
- Enter fabric weight in grams.
- Enter sample area in cm² or m².
- Automatic GSM calculation.
- Display results in g/m².
- Simple and user-friendly interface.

## Formula

GSM = Fabric Weight (g) / Fabric Area (m²)

## Technologies Used

- Python
- Streamlit
- GitHub

## Installation

Install the required library:

pip install -r requirements.txt

## Run Application

streamlit run App.py

## Deployment

1. Upload all three files to GitHub.
2. Open Streamlit Community Cloud.
3. Connect your GitHub repository.
4. Select App.py as the main file.
5. Click Deploy.

## Application Purpose

This application helps textile engineering students
calculate fabric GSM quickly and easily.
